<h1>Windows Server Homelab</h1>

<h2>Description 💻</h2>
<p>The purpose of this homelab is to demonstrate the utilization and configuration of Windows Server 2025 to simulate enterprise Windows environments. For this particular homelab, I used VMWare Workstation Pro to virtualize the server operating system so I could configure its use. The main benefit to virtualization is the ability to gain hands on learning with the server technology without job experience. 

Some main features of Windows Server 2025 include
- Active Directory
- Group Policy
- DHCP server
- DNS server
- Azure Arc
- Copilot or
- Hyper-V technology </p>

<p>Note: Some services such as Active Directory would have their own dedicated repository while others can be covered in a much smaller context and described in this single main repository.</p>
