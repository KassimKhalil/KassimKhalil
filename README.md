<h1>Active Directory Homelab</h1>

<h3>Description</h3>
<p>Active Directory is a main service offered by Window Server operating systems. Active Directory is a directory system used to manage the affairs of different companies. 

Active Directory also offers features such as:
- Creating and managing user accounts and computer objects
- Authenticating users as they log into the domain
- Granting or denying access control permissions for users
- Organizing users and computers into groups (OUs)
- Hierarchical domain structures
- DNS Integration and
- LDAP support</p>
<h2> Homelab Purpose</h2>
<p>The purpose of this homelab is to demonstrate my understanding of configuring Active Directory Roles and Features alongisde tools in a simulated virtualized environment. This demonstration should prove my ability to modify settings and features in Active Directory to showcase applicable skills that can be used in entry-level IT positions. </p>
